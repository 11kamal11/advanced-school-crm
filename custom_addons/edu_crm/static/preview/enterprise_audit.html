edu_fee.py · L33,49–53
edu_dashboard.py
All monetary amounts are Float — no currency symbol or multi-currency
amount, net_amount, paid_amount, balance on EduFee; fee_due_amount on Dashboard — all plain fields.Float. No ₹/$/€ symbol in list views, no multi-currency support, and widget="monetary" silently falls back to a default currency.
Add currency_id = fields.Many2one('res.currency', related='company_id.currency_id') and change all monetary fields to fields.Monetary
High
edu_dashboard.py · L31–35
Dashboard loads full fee/student tables into Python memory on every open
_safe_sum does .search(domain).mapped(field) — fetches all matching records into Python, then sums them. On a school with 2,000 fee records, every dashboard load pulls 2,000 rows. Should use read_group for a single aggregated SQL call.
Replace with read_group(domain, [field], []) — returns one row with the sum

Create an Operations parent menu and move attendance/leave/announcements under it

edu_fee.py · L24–35
No unique constraint on FeeStructure — duplicate fees silently created
Two fee structures for the same class + academic year + fee type can be created without any warning. Students then get double fee assignments with no system-level guard.
